# Dudas de geocodificación — Expedición Inka 2026

Revisión hecha el 2026-11-28 sobre `scripts/reporte.csv` (regeneración con los 4 chats).

Este archivo es para revisar juntos los casos que no son 100% claros. Los que están
marcados como **EXCLUIDO** no se publican en el mapa hasta que los confirmemos. Los
**CORREGIDO** sí se publican, pero conviene verificar que la localidad elegida sea la
correcta.

Para resolver un caso:

- Si está bien: no hay que hacer nada.
- Si está mal: agregarlo a `excluir_usuarios` o a `corregir` en `scripts/revision.json`
  y volver a correr `python3 scripts/generar_localidades.py`.

## 4. Cómo seguir

1. Revisar los casos de la sección 1 y 2.
2. Editar `scripts/revision.json` si hay que mover alguno.
3. Regenerar:

   ```bash
   cd ~/proyectos/Expedicion-Inka-2026
   python3 scripts/generar_localidades.py
   ```

4. Publicar:

   ```bash
   git add localidades.geojson scripts/revision.json dudas.txt
   git commit -m "Ajustar lugares dudosos"
   git push origin main
   ```
